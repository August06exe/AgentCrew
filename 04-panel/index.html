备份 / 恢复

整个存档打成一个 .asave 单文件包——备份、换机搬家、给朋友发个档

导出存档

把整个存档（主人档案 + 全部顾问数据与信箱）打包为 crew-save-<时间>.asave，落在存档上级目录。

导入存档（整档替换）

两步走：先预览检查，确认后才动手。目标存档非空时自动先备份为 crew-save-auto-backup-*.asave；旧版本包导入后自动阶梯迁移；全新实例无档也可直接导入。

比程序新的包会被拦截（防降级安装）——确需强装请用命令行 python 05-scripts/save.py import <文件> --force，面板不提供强制口。

或
⚠️ 导入将整档替换当前存档（旧档自动备份）。lite 独立助理自带的 _save 不在实例包内，搬家请单独拷贝它的 _save。

导入前建议先在「总览」页暂停各助理；导入瞬间数据页可能短暂打不开，属正常。
