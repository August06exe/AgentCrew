# DESIGN.md — AgentCrew 周报设计系统 v2（light / warm-editorial）

> 设计来源：OpenDesign 官方设计系统库 `design-systems/warm-editorial`（本机 `D:\Software\Open Design\resources\open-design\design-systems\`），按周报场景适配。
> v1 深色版被主人否决（"谁让你搞黑布隆冬的"）——**本生态一切界面默认浅色暖纸风**，深色需主人逐次明确要求。
> 本文件是周报及一切报表页的**设计唯一权威**；改设计=改本文件，再照文件重生成页面。

## 1. 主题与气质

**「私人顾问的周度简报」——一份印在暖纸上的杂志栏目，克制、温润、值得收藏。**
- 主感觉：New Yorker 专栏式的编辑排版；健康数据是内容，不是炫技对象。
- 三禁：禁深色底、禁渐变、禁 emoji 进产品文案。
- 允许：✓ ⚠ → 少量状态符号；每页最多一个赤陶土强调元素。

## 2. 色彩令牌

| 令牌 | 值 | 用途 |
|------|----|------|
| `--paper` | `#FAF7F2` | 页面底色（暖纸，禁纯白大面积使用） |
| `--card` | `#FFFFFF` | 白卡片 |
| `--ink` | `#1C1A17` | 正文（暖近黑，禁纯黑） |
| `--muted` | `#8A817A` | 次要文字/元数据 |
| `--accent` | `#C0512F` | 赤陶土：关键数字/主进度条/当周标签（每屏限一个主角） |
| `--forest` | `#2F5B4F` | 森林绿：区块标题、分隔、达标状态 |
| `--line` | `rgba(28,26,23,.12)` | 描边/分隔线 |
| `--good / --warn / --bad` | `#2F5B4F / #B08968 / #A63D2F` | 状态语义（暖调） |
| `--empty` | `#EAE4DB` | 未记录/空柱 |

## 3. 字体

- 大标题/关键数字：衬线 `'Georgia', 'Times New Roman', 'Songti SC', serif`——**重要数字必须衬线**（定价、统计同规则）。
- 正文/标签：`'Segoe UI', 'Microsoft YaHei', system-ui, sans-serif`。
- 字阶 px：12 · 14 · 16 · 20 · 28 · 40；正文行高 1.6，标题 1.2。
- 全部数字 `tabular-nums`；40px 以上标题 letter-spacing -0.02em。

## 4. 布局与间距

- 页宽 `max-width: 860px` 居中；卡片内边距 24px；卡片间距 16px。
- 圆角 16px（禁 >24px 或 <8px）；卡片描边 1px 森林绿 8% 透明度。
- 阴影只有一级：悬停/浮层 y+2px blur16 前景 6%；**输入框、标题区一律无阴影**。
- 两栏栅格 `repeat(2,1fr)`，<720px 折单栏。

## 5. 组件规范

- **KPI 卡**：白底；标签 muted 12px → 数字 40px 衬线（默认 ink，达标/关键者 accent）→ 注脚 12px muted。
- **教练点评**：白底卡 + 左侧 3px 赤陶土竖线；`教练视角` 标签用 forest 色粗体。
- **图表**：折线=赤陶土 2px + 实心点；缺口柱=正向赤陶土/负向 `--bad`/未记录 `--empty`；蛋白达标柱按 good/warn/bad 分级；目标进度条 8px 圆角赤陶土。
- **页脚**：数据黄金源声明 + 生成时间，muted 12px，上方 1px 分隔线。

## 6. 图表与文案

- 折线/柱状全部 SVG/DIV 手绘，零图表库零外链；坐标只标极值（muted 11px）。
- 教练点评规则：客观、可执行、不评价身材不打鸡血；缺数据如实标「未记录」。

## 7. 布局模板

```
[页头 周次+日期范围]        [‹ 周切换 ›]
[教练点评卡]
[KPI×4]

[每日缺口 | 蛋白达标]（两栏）

[页脚 黄金源声明]
```
